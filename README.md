# 🎯 Классификация точек перцептроном

Реализация однослойного перцептрона с нуля на NumPy. Без фреймворков — только чистый код, чтобы разобраться, как устроен базовый механизм обучения нейросетей: веса, softmax, обратное распространение ошибки.

## Назначение

Задача — классифицировать точку на плоскости по четвертям координатной системы. Несмотря на простоту постановки, проект демонстрирует полный цикл обучения модели: инициализацию весов, прямой проход, расчёт градиента и обновление параметров.
